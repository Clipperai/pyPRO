# Day 10 — Automation & Website Opener

**Focus:** automation with webbrowser — opening websites by name, loops, and a voice (pyttsx3) version.

## Files in this day

- **Auto_py.py** — Website Opener v1: open a website by name with webbrowser
- **Auto_py_lev_2.py** — Website Opener Level 2: looping version — open more than one website
- **Auto_py_v2.py** — Website Opener v2: voice version using pyttsx3 text-to-speech

## What I learned

- `webbrowser.open()` opens a URL in the browser — it needs a URL, not a program name
- Matching a typed command with `if` / `elif` branches
- A loop with a yes/no choice to repeat an action
- A dictionary can map names to URLs cleanly (v2)

## How to run

```
python Auto_py.py
python Auto_py_lev_2.py
```
