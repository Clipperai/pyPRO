# Day 1 — Python Basics

**Focus:** print, variables, user input, and numbers — plus my first mini project.

## Files in this day

- **1.hello.py** — my first Python program: prints "Hello World!"
- **2.Variables.py** — taking name and age from the user with `input()`
- **3.Numbers.py** — basic arithmetic (+, -, *, /) and assigning multiple values in one line
- **4.Mini Projects/Calculator_v1.py** — calculator that works on a list of numbers (+, -, *, /)
- **4.Mini Projects/Calculator_v1.5.py** — menu calculator with functions: square, cube, factorial, even/odd checker

## What I learned

- `input()` always gives a string — convert it with `int()` before maths
- Variables, numbers, and basic operations
- Writing functions and running a menu in a `while True` loop

## How to run

```
python 1.hello.py
python "4.Mini Projects/Calculator_v1.5.py"
```
