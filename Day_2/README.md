# Day 2 — Lists, Loops & To-Do App

**Focus:** lists, for loops, and building a To-Do App in three versions.

## Files in this day

- **list.py** — creating a list and adding items with `append()`
- **loops.py** — collecting marks in a list using a for loop
- **To-do-App/v1.py** — simple To-Do App: enter your tasks, see the list
- **To-do-App/v2.py** — menu-based To-Do App: add tasks, view tasks, exit
- **To-do-App/v3.py** — the To-Do App as a Streamlit web app

## What I learned

- Lists: creating them, adding items with `append()`, printing them
- Using a for loop to take repeated input
- Building the same app step by step — v1 (basic) → v2 (menu) → v3 (web UI)

## How to run

```
python list.py
python To-do-App/v2.py
streamlit run To-do-App/v3.py
```
