# Day 5 — Dictionaries & Contact Book

**Focus:** dictionaries — creating, adding/updating, looping with .items() — and a Contact Book in three versions.

## Files in this day

- **dict.py** — creating a dictionary and printing a value
- **dict_loops.py** — updating contacts and looping through them with .items()
- **add&update.py** — adding contacts to a dictionary, then updating one
- **Contact-Book/v1.py** — Contact Book v1: add one contact and print saved contacts
- **Contact-Book/v2.py** — Contact Book v2: menu version — add, view, search and exit
- **Contact-Book/v3.py** — Contact Book v3: the Contact Book as a Streamlit web app

## What I learned

- Dictionaries store data as key-value pairs
- Adding a new key and updating an existing key use the same syntax
- Looping with `.items()` gives both the key and the value
- Building the same project in versions — basic, menu, then a web app

## How to run

```
python dict.py
python Contact-Book/v2.py
streamlit run Contact-Book/v3.py
```
