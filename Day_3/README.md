# Day 3 — Functions & Number Toolkit

**Focus:** functions — defining them, passing values, returning results — and building a Number Toolkit in two levels.

## Files in this day

- **square.py** — square of a number (the basic version)
- **function.py** — my first function: define it, call it
- **sq_list.py** — squares of a list, built with a loop
- **Number_toolkit_lev_1.py** — Number Toolkit Level 1: square, cube, even/odd and factorial as functions, all printed for one number
- **Num_Toolkit_lev_2.py** — Number Toolkit Level 2: the same toolkit as a menu program (choose an operation, exit when done)

## What I learned

- Defining functions with `def` and returning values with `return`
- Reusing the same functions in two programs (direct print vs menu)
- Recursion — factorial calls itself
- A menu loop with `while True` and `break`

## How to run

```
python square.py
python Num_Toolkit_lev_2.py
```
